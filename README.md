# ToDoリスト

やることを追加、完了、削除できるシンプルなWebアプリです。データはブラウザに保存されるので、閉じても消えません。

## できること

- やることの追加（追加ボタン、または Enter キー）
- 完了マークの切り替え（チェックと打ち消し線で表示）
- 削除と、削除の取り消し（通知の「元に戻す」を8秒以内に押す）
- 別のタブで変更した内容の自動反映
- スマホ表示とダークモードへの対応

## 使い方

Node.js が必要です。

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 本番用にビルド |
| `npm start` | ビルドしたアプリを起動 |
| `npm run lint` | ESLint でコードを検査 |

## データの保存先

データはブラウザの `localStorage`（キーは `todos`）だけに保存され、サーバーには送信されません。そのため、次の点に注意してください。

- 別のブラウザや端末とは共有されません。
- ブラウザのサイトデータを消すと、データも消えます。

## 技術構成

- [Next.js](https://nextjs.org)（App Router）
- TypeScript
- Tailwind CSS

アプリの本体は `app/page.tsx` にあります。
